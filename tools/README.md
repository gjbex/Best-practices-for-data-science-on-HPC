# Tools

This directory contains various tools that can be useful in the context of data
science on HPC systems.

Note: these tools have been developed and tested on Vlaams Supercomputing
Centrum infrastructure, and may need to be adapted for other HPC systems.


## What is it?

1. `conda_containers`: tool to easily create apptainer images containing a
   conda environment specified by an `environment.yml` file.
1. `r_containers`: tool to easily create apptainer images containing R, system
   dependencies and R packages.
